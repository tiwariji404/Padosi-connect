# PadosiConnect - Neighborhood Community Web Application

Full-Stack web application built using **React.js**, **JavaScript**, **Node.js**, **Express.js**, and **Firebase**.

## Architecture

- **Frontend**: `frontend/` - React.js (Vite, JavaScript, Vanilla CSS, Firebase Client SDK)
- **Backend**: `backend/` - Node.js + Express.js REST API with CORS and JSON endpoints
- **Firebase**: Firebase Authentication, Cloud Firestore / Realtime DB, and Firebase Storage integration

## Available Scripts (Root)

```bash
npm run dev         # Run both frontend and backend concurrently
npm run frontend    # Run Vite React development server (http://localhost:5173)
npm run backend     # Run Express API server (http://localhost:5000)
npm run build       # Build frontend production bundle
npm run start       # Start backend server
```
